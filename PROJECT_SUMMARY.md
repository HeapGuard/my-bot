# 🚀 StoriesHub Telegram Bot — Итоговый отчет и сводка проекта

## 📌 Описание проекта
Telegram-бот **StoriesHub** (`@VPNUniversalBot`) для автоматического создания вирусных каруселей слайдов вертикального формата **1080×1350 px** для Threads, Instagram и Telegram Stories.

---

## 🛠 Техническая архитектура и стек

1. **Telegram Engine (`bot.py`)**:
   - Фреймворк `aiogram 3`.
   - Обработка входящих запросов, отправка готовых альбомов карточек и формирование `.zip` архива.
   - База данных SQLite (`db/database.py`).

2. **LLM Сценарист (`core/llm.py`)**:
   - Интеграция с **Google Gemini API** (`google-genai`).
   - Каскад моделей с авто-переключением (fallback).
   - Защита от ошибок форматирования JSON.
   - Локальный роутер разбиения текста (на случай лимитов API / 429 ошибки).

3. **Иллюстрации (`core/image_gen.py`)**:
   - Генерация темно-атмосферных фонов с помощью **Pollinations FLUX**.
   - Резервный источник атмосферных фото через Unsplash.
   - Корректный менеджмент асинхронных HTTP-сессий.

4. **Рендерер слайдов (`core/renderer.py` & `core/templates/`)**:
   - Шаблонизатор **Jinja2** (`slide.html`, `style.css`).
   - Отрисовка высокого разрешения через headless **Playwright Chromium**.
   - Увеличенные шрифты (48px / 64px) для мобильных экранов, аккуратные рамки, нумерация слайдов и фирменный логотип Threads (`threads-logo.webp`).

## 🌐 Развертывание на VPS

- **IP сервера**: `89.169.53.163`
- **Путь на сервере**: `/root/my-bot`
- **Автономная служба**: `storieshub.service` (Systemd)

### Полезные команды для управления на VPS:
- **Проверить статус**: `systemctl status storieshub`
- **Смотреть логи 24/7**: `journalctl -u storieshub -f`
- **Перезапустить бота**: `systemctl restart storieshub`
- **Остановить бота**: `systemctl stop storieshub`
