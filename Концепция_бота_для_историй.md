# Концепция Telegram-бота StoriesHub

## Идея

Бот принимает тему или готовую историю (например, из Pikabu) и
превращает её в вирусную карусель для Threads.

## Конвейер

1.  Пользователь отправляет тему или историю.
2.  ИИ анализирует сюжет, персонажей, конфликт и мораль.
3.  Делает художественный рерайт без изменения сути.
4.  Разбивает историю на 6--8 карточек.
5.  Добавляет:
    -   цепляющий заголовок;
    -   клиффхэнгеры в конце карточек;
    -   одну акцентную карточку с сильной цитатой;
    -   финальный вывод;
    -   вопрос, провоцирующий обсуждение.
6.  Возвращает JSON:

``` json
{
  "title":"",
  "slides":[
    {"type":"cover","title":"","text":"","image_hint":""},
    {"type":"story","text":"","image_hint":""},
    {"type":"quote","text":"","image_hint":""},
    {"type":"story","text":"","image_hint":""},
    {"type":"ending","text":"","question":"","image_hint":""}
  ]
}
```

## Типы карточек

### Cover

Заголовок до 12 слов. Только интрига, без спойлеров.

### Story

45--70 слов. Один смысловой эпизод. Последняя строка вызывает желание
листнуть дальше.

### Quote

Минимум текста. Сильная мысль: \> «Именно тогда я понял одну простую
вещь.»

### Ending

Короткий вывод + вопрос, требующий личного выбора читателя.

## Правила повествования

-   Не менять факты.
-   Усиливать атмосферу.
-   Писать живым языком.
-   Без штампов и «как нейросеть».
-   Каждый экран читается за 5--8 секунд.

## Подсказки для иллюстраций

ИИ не генерирует изображения, а создаёт `image_hint` для каждого экрана.

Пример: - Сцена - Главный объект - Настроение - Свет - Цветовая
палитра - Что оставить свободным под текст

Пример: \> Старый металлический ключ на мокром асфальте ночью. Холодная
палитра, мягкий туман, драматичный свет, 30% свободного пространства
снизу.

## Самопроверка

Перед публикацией ИИ оценивает: - силу первого экрана; - удержание
внимания; - эмоциональность; - естественность; - желание комментировать.

Если любой критерий \< 9/10 --- переписывает автоматически.

## Шаблон карусели

-   Формат: 1080×1350 (4:5)
-   Чёрный фон с лёгкой текстурой
-   Тонкая серебристая рамка
-   Белая типографика
-   Аккаунт сверху
-   Номер карточки снизу
-   Иллюстрация только внутри безопасной зоны
-   Единый визуальный стиль

## Будущее

-   Генерация нескольких вариантов финального вопроса.
